# CatWeb Code Generator

`catweb_generator.py` generates a tiny CatWeb starter project (HTML/CSS/JS).

## Usage

```bash
python3 catweb_generator.py my-catweb
```

Optional flags:

- `--title "My CatWeb"`
- `--heading "Welcome"`
- `--overwrite`

## Test

```bash
python3 -m unittest discover -s tests
```
